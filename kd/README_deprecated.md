# Deprecated KD scratch folder

This folder is kept for historical experiment records only. The retained and
reproducible knowledge-distillation version is now under `EANN/`:

- `EANN/train_baseline.py`
- `EANN/train_teachers.py`
- `EANN/train_distillation.py`
- `EANN/evaluate_kd_ablation.py`

Use `EANN/evaluate_kd_ablation.py` to generate the thesis comparison between
EANN without KD and EANN with KD.
